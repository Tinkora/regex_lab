# regex_lab 产品规格

## 产品一句话

浏览器原生的正则表达式测试实验室。实时匹配、捕获组提取、替换预览、多语言代码生成，全部在 Rust/WASM 中运行。

## 目标用户

- 需要快速测试和调试正则表达式的开发者
- 需要生成多语言等效正则代码的跨语言开发者
- 希望离线、零数据外泄地进行正则测试的安全敏感场景
- 需要教学或演示正则表达式的讲师和内容创作者

## 核心体验

1. 用户在左侧输入正则表达式模式，UI 实时反馈模式是否合法（绿色/红色边框）
2. 勾选所需标志位：i (忽略大小写)、m (多行)、s (点匹配换行)、U (非贪婪)、x (忽略空白)、u (Unicode)
3. 在测试文本区域输入或粘贴测试字符串
4. 匹配结果在下方实时高亮显示，捕获组以表格形式展示
5. "替换"标签页提供替换功能，先预览再确认
6. "代码生成"标签页支持选择目标语言，一键复制等效正则代码片段

## 功能范围

### 正则匹配（match 标签页）
- 首次匹配：返回第一个匹配的位置、文本和捕获组
- 全局匹配：返回所有匹配结果，支持内联高亮显示
- 捕获组表格：同时展示编号捕获组和命名捕获组
- 匹配统计：匹配总数和位置信息

### 替换（replace 标签页）
- 替换预览：实时展示替换后文本
- 单次替换和全局替换模式
- 匹配计数

### 分割（通过 API 支持）
- 按模式分割文本

### 代码生成（code 标签页）
- 支持语言：JavaScript、Python、Rust、Go
- 生成包含完整导入语句和注释的可用代码片段
- 一键复制按钮

### 模式验证
- 实时语法检查
- 清晰的错误信息（中文）

## 标志位说明

| 标志 | Rust 等价 | 说明 |
|------|-----------|------|
| i | case_insensitive | 忽略大小写匹配 |
| m | multi_line | ^ 和 $ 匹配行首/行尾 |
| s | dot_matches_new_line | . 匹配包括换行在内的所有字符 |
| U | swap_greed | 交换贪婪/非贪婪语义 |
| x | ignore_whitespace | 忽略模式中的空白和注释 |
| u | unicode | 启用 Unicode 感知匹配 |

## 非目标

- 不支持正则替换中的回调函数（仅限于简单字符串替换）
- 不支持 PCRE 独有的特性（反向引用条件、递归等）
- 首版不做正则可视化/图表示
- 不做正则库/SaaS/API 服务
- 不做服务端处理（仅浏览器 WASM）

## 验收标准

- 模式输入时实时反馈合法性
- 所有标志位组合正确生效
- 匹配结果位置和内容准确
- 捕获组（含命名组）提取正确
- 替换结果符合预期
- 代码生成片段各语言均合法可运行
- 输入/输出不触发浏览器外网络请求
