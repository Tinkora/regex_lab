核心功能

为开发者量身打造的正则测试体验

实时匹配

输入即反馈。正则模式验证和匹配结果实时更新，无需手动触发。

捕获组提取

内联高亮显示匹配文本，表格展示所有编号捕获组和命名组。

替换预览

先预览替换效果，确认后再复制结果。支持 $1/$name 捕获组引用。

多语言代码生成

一键生成 JavaScript、Python、Rust、Go 等效正则代码片段。

六种标志位

完整支持 i (大小写)、m (多行)、s (点全匹配)、U (非贪婪)、x (忽略空白)、u (Unicode)。

隐私优先

所有处理在浏览器 WASM 内完成，测试文本绝不离开本地。

安装与运行

需要 Rust 工具链和 wasm-pack。一行命令启动本地实验室。

1. 克隆并构建

# 克隆仓库
git clone https://github.com/Tinkora/regex_lab.git
cd regex_lab

# 构建 Web WASM
wasm-pack build --target web crates/regex_lab_web

2. 启动本地服务器

cp crates/regex_lab_web/pkg/* crates/regex_lab_web/static/pkg/
cd crates/regex_lab_web/static
python3 -m http.server 8080

# 浏览器打开 http://localhost:8080

代码生成示例

输入正则模式，选择目标语言，一键生成可运行的代码片段。

JavaScript

// 正则表达式: \d{3}-\d{4}
const regex = /\d{3}-\d{4}/g;
const matches = [...input.matchAll(regex)];

Python

import re
pattern = r'\d{3}-\d{4}'
matches = re.findall(pattern, text)

Rust

use regex::Regex;
let re = Regex::new(r"\d{3}-\d{4}").unwrap();
let replaced = re.replace_all(input, "XXX-****");

Go

import "regexp"
re := regexp.MustCompile(`\d{3}-\d{4}`)
matches := re.FindAllString(input, -1)
